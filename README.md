# アトピアクリニック HPリニューアル

熊本県菊池郡菊陽町のアトピー性皮膚炎専門クリニック「アトピアクリニック」のリニューアルサイトです。
静的HTML/CSS/JSのみで構成されており、`index.html` をブラウザで開くだけで確認できます。

## コンセプト

- **キャッチコピー**: 「アトピーを、一生の悩みにしない。」
  院長・稲葉葉一先生の著書『アトピー性皮膚炎は初期治療を間違えると、一生皮膚トラブルを抱える事になる！』の信念を、患者さんへの約束の言葉として反転させたもの。
- **予約導線**: 完全予約制のため、「初診＝電話」「再診＝Web（ドクターキューブ）」の2経路をヘッダー・ヒーロー直下・予約セクション・クロージング・モバイル固定バーで一貫して提示。
- **デザイン**: 白磁×深緑を基調とした日本の医療機関らしい清潔感のあるトーン。予約CTAのみ柿色で統一し、迷わず押せるように。キャッチコピー・院長の言葉は明朝体（しっぽり明朝）。
